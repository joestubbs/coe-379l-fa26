Unit 2: Introduction to Formal Methods 
======================================

In this second unit, we provide an introduction to Formal Methods and the Lean programming language and 
interactive theorem prover. We motivate the unit with an initial treatment of specifications, properties and 
proofs with a particular focus on modeling program executions as states and transitions. We then cover the basics 
of Lean syntax, including syntax for theorem proving (definitions, theorems, tactics, etc.) as well as functional 
programming (variables and basic types, computable and noncomputable functions, basic data structures, etc.)
