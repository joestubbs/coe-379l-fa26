Getting to Know Lean
====================

This reading consists in going over the first chapter of the book
`Functional Programming in Lean <https://lean-lang.org/functional_programming_in_lean/Getting-to-Know-Lean/#getting-to-know>`_.

This is a book that goes into some detail about using Lean as a functional programming
language. Several of the chapters may require some deeper familiarity with the theory
of types than what we will address in class. As such, the requirements for this reading
are:

1. Read `Chapter 1 <https://lean-lang.org/functional_programming_in_lean/Getting-to-Know-Lean/#getting-to-know>`_
   and try to reproduce some of the examples shown in your own Lean environment.
2. Select at least **two exercises** from `Section 1.6.5 <https://lean-lang.org/functional_programming_in_lean/Getting-to-Know-Lean/Polymorphism/#polymorphism-exercises>`_
   and solve them.
