Playing the Natural Number Game
===============================

This reading consists in playing a game. 
`The Natural Number Game <https://adam.math.hhu.de/#/g/leanprover-community/NNG4>`_ is
a guided game/tutorial that helps developing an intuition about proofs in Lean.
It doesn't require any knowledge about how to write proofs, and it works like a puzzle.
At the end of the game you will understand the main ideas about proving statements in
Lean.

If you want to play other games, there are several ones at the `Lean Game Server <https://adam.math.hhu.de/>`_,
with varied levels of depth on the topics. Some other recommended games are:

- `Set Theory Game <https://adam.math.hhu.de/#/g/djvelleman/stg4>`_
- `Reintroduction to Proofs <https://adam.math.hhu.de/#/g/emilyriehl/reintroductiontoproofs>`_
- `Introduction to Program Verification <https://adam.math.hhu.de/#/g/GitHubAvailable/ProgramVerificationGame>`_. *Warning*, we haven't tested this game.
