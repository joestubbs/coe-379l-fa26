Unit 3: Patterns and Architecture for Neurosymbolic Systems
==========================================================

In this last unit, we bring together the previous two units to describe how to improve the reliability of software systems 
that leverage AI through the use of formal methods. We will walk through architecture designs and implementation details 
for several example applications. The techniques we will leverage will be similar in each case: the primary application will leverage AI 
to propose an action or answer, and a formal methods component will validate certain rules about the proposal.
